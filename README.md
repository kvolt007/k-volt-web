# K-Volt Web

Sitio web oficial de **K-Volt**, orientado a servicios eléctricos domiciliarios, comerciales, para PYMEs e industrias en Rosario y Gran Rosario.

## Estructura

- `index.html` — página principal y SEO estructurado.
- `styles.css` — diseño responsive/mobile-first.
- `script.js` — menú, FAQ, formulario y enlaces de contacto.
- `robots.txt` — directivas para buscadores.
- `sitemap.xml` — sitemap inicial.
- `manifest.webmanifest` — metadatos web.
- `assets/` — favicon y recursos visuales.
